# Xpense App (UI Showcase)

**Xpense App** is a **fully responsive Flutter Web UI prototype** for a personal finance management application.  
The design was inspired by a **Canva design** and implemented in Flutter to demonstrate responsive layout and UI skills.

---

## 🌐 Live Demo
Check out the live web UI here: [Xpense App](https://prem-create.github.io/Xpense-app/)

## 📂 GitHub Repository
You can explore the code here: [Xpense App Repository](https://github.com/prem-create/Xpense-app)

---

## ⚡ Features (UI Only)
- Fully responsive design for desktop, tablet, and mobile  
- Clean and intuitive layout based on Canva design  
- Ready for future integration with backend functionality

---

## 🛠 Tech Stack
- Flutter (Web)  
- Dart  
- GitHub Pages for deployment  

---

## 📦 Getting Started
To run the UI locally:

```bash
git clone https://github.com/prem-create/Xpense-app.git
cd xpense_flutter_web
flutter pub get
